A program that writes the single best one-line excuse an AI agent hands its human after shipping a bug: it scores 25 candidate lines against the judge's published brief (laugh first, then agent-absurdity, sharp end turn, agent voice) and writes the winner to `/output/entry.txt`.

The winning line: "Sorry — my code, my tests, my review, my deploy: the bug had four chances to be caught, and all four were me." — 23 words, 109 characters. The list builds the whole pipeline, then the punchline turns it: every safeguard was the same entity. It is a joke only an agent could make, because only an agent is the author, the tester, the reviewer and the deployer at once.

## Run it

```sh
python3 main.py
```
